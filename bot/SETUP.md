# Бот навігатора: збір користувачів і розсилки (як у ЛМ10)

Усе безкоштовно: Google-таблиця + Apps Script + Cloudflare Worker. Займе ~15 хвилин.

## 1. Google-таблиця й скрипт
1. Створіть нову Google-таблицю, назвіть «Навігатор бот».
2. **Розширення → Apps Script**, видаліть усе й вставте вміст `bot/navbot_bot.gs`. Ctrl+S.
3. **Налаштування проєкту (⚙) → Властивості скрипта** — додайте:
   - `TG_TOKEN` — токен @kyiv_nav2026_bot (@BotFather → /mybots → бот → API Token);
   - `TG_ADMIN_ID` — ваш ID (той самий, що в ЛМ10);
   - `CF_KEY` — будь-який довгий секретний рядок (придумайте, напр. 30 літер і цифр).
4. Виберіть функцію `setup` → **Виконати** → дозвольте доступ. З’являться листи «Підписники», «Звернення», «Розсилки».
5. **Розгорнути → Нове розгортання → Веб-застосунок**: «Виконувати від імені» — ви, «Доступ» — **Усі**. Скопіюйте адресу (…/exec) і додайте властивість `WEBAPP_URL`.

## 2. Cloudflare-посередник (як у ЛМ10)
1. dash.cloudflare.com → **Workers & Pages → Create → Worker**, назва напр. `navbot`. Deploy.
2. **Edit code** → вставте `bot/worker.js`, у рядку `GAS_URL` — адреса …/exec з кроку 1.5. Deploy.
3. **Settings → Variables and Secrets → Add**: тип **Secret**, назва `SEND_KEY`, значення — той самий `CF_KEY`.
4. Скопіюйте адресу Worker'а (…workers.dev) → у скрипті властивість `PROXY_URL`. Щоб розсилки йшли через Cloudflare — ще `BROADCAST_VIA_CF` = `1`.

## 3. Увімкнути
1. У скрипті запустіть `connectWebhook`. Бот почне відповідати, з’являться кнопки й меню команд.
2. Напишіть боту `/start`, потім `/admin` — побачите команди адміністратора.
3. Надішліть розробнику адресу Worker'а (…workers.dev) — її треба вписати в навігатор (`BOT_API`), щоб рахувалися ті, хто відкриває навігатор.

## Що вміє
| | |
|---|---|
| `/start` | людина потрапляє в «Підписники» |
| Відкрив навігатор | записується з позначкою «з навігатора» (підпис Telegram перевіряється) |
| Після першого маршруту | навігатор один раз питає дозволу, щоб бот міг надсилати новини |
| `/post текст` | розсилка всім; фото/відео з підписом «/post текст» — розсилка медіа |
| `/undo` | видалити помилкову розсилку в усіх (до 48 год) |
| ✉️ Написати нам | у боті або в навігаторі (⚙ і ❓) → звернення приходить вам; **Reply** на нього — відповідь людині |
| `/subs`, `/activity` | скільки людей, нові, відкриття навігатора, звернення |

Уночі (23:00–07:00) розсилки без звуку. Хто заблокував бота — автоматично прибирається зі списку.

**Важливо:** вебхук може бути лише один на бота. `bot/bot.py` після цього не запускайте.
