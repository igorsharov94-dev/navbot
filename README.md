# Навігатор без GPS — @kyiv_nav2026_bot

Міні-застосунок Telegram для авто: веде маршрутом, навіть коли під час тривоги GPS глушать або підміняють.

**Сайт:** https://igorsharov94-dev.github.io/navbot/ (його відкриває кнопка «Навігатор» у боті)

## Що вміє

- **Фільтр підміни GPS**: стрибки координат, нереальна швидкість, «застиглі» точки відкидаються, навігатор переходить на датчики.
- **Навігація за датчиками**: гіроскоп розпізнає повороти й прив’язує позицію до перехресть маршруту, акселерометр бачить зупинки, світлофори уточнюють позицію.
- **Слабкий GPS** (±30–80 м) лише м’яко підтягує позицію — стрілка не стрибає.
- **Звірка з вигинами дороги**: історія гіроскопа порівнюється з формою маршруту — позиція уточнюється і на плавних вигинах, а не лише на перехрестях.
- **Швидкість за вібрацією**: поки GPS працює, навігатор вчиться, яка тряска відповідає якій швидкості саме у вашій машині.
- **Самоперевірка точності**: поки GPS є, паралельно рахує позицію «наче без GPS» і показує в ⚙ помилку через 1 і 2 хв (нову й за старим способом).
- **Журнал поїздки** (⚙ → 📄): файл для налаштування точності. Містить маршрут і координати.
- **Неонова 3D-карта** або звичайна (🌃/🗺), камера за машиною: 3D / 2D / північ угорі.
- **Місця**: 🛒 магазини, 💊 аптеки, ⛽ заправки, 🛡 укриття — вздовж маршруту або поруч на мапі.
- Спідометр, мітки 📌, голосові підказки українською («на 2-му світлофорі праворуч»), інструкція ❓.

## Файли

| Файл | Що це |
|---|---|
| `index.html` | Міні-застосунок: інтерфейс, GPS, датчики, камера, голос |
| `core.js` | Розрахунки: маршрут, повороти, світлофори, проєкція на маршрут |
| `mapview.js` | Карта MapLibre: стилі «Класика» і «Неон 3D», маркери, камера |
| `pois-kyiv.json` | База Києва з OpenStreetMap: ~5600 місць і ~1600 світлофорів (щоб не залежати від перевантаженого сервера Overpass) |
| `test/` | Тестова копія сайту для перевірки змін перед викладкою |
| `bot/` | Бот як у ЛМ10 (`navbot_bot.gs` + `worker.js`): збір користувачів, розсилки `/post`, «Написати нам». Інструкція — `bot/SETUP.md`. `bot.py` — старий простий варіант |
| `tests/` | Перевірки: `node tests/test_core.js`, `node tests/test_profile.js`, `node tests/gas/test_bot.js` (бот) |

## Бот (необов’язково)

Кнопка «Навігатор» налаштована в @BotFather → `/setmenubutton`, сервер для неї не потрібен.
`bot/bot.py` додає привітання й `/help`:

```
cd bot
pip install -r requirements.txt
cp .env.example .env      # впишіть BOT_TOKEN від @BotFather
python bot.py
```

Файл `.env` з токеном **ніколи не завантажуйте** на GitHub — він у `.gitignore`.

## Оновлення в Telegram

Telegram кешує сторінку. Після змін повністю закрийте Telegram або змініть посилання в @BotFather на `…/navbot/?v=N` з новим числом.
